# Universal Ko'p Tilli Telegram Tarjimon Bot (PRO)

Ushbu bot dunyoning eng mashhur tillari va 100+ xorijiy tillarni tezkor, sifatli va avtomatik tarjima qilish uchun yaratilgan.

## Asosiy Tillar:
- 🇰🇷 **Koreys tili** (Hangul va talaffuz transkripsiyasi bilan)
- 🇬🇧 **Ingliz tili**
- 🇯🇵 **Yapon tili** (Kanji/Kana va Romaji talaffuzi bilan)
- 🇩🇪 **Nemis tili**
- 🇷🇺 **Rus tili**
- 🇺🇿 **O‘zbek tili**
- 🇹🇷 **Turk tili**
- 🌐 **Dunyodagi 100+ boshqa tillar**

## Kompyuterni ishlatmaganda ham bot doimiy ishlashi uchun:
- **`kompyuterni_doimiy_ishlatish.bat`** — ushbu faylni bir marta ishga tushirsangiz, kompyuter hech qachon uxlab qolmaydi va noutbuk qopqog'i yopilganida ham bot 24/7 ishlashda davom etadi.

## Boshqaruv fayllari:
1. **`start_bot.bat`** — botni hozir fonda ishga tushirish.
2. **`stop_bot.bat`** — botni to'xtatish.
3. **`check_bot.bat`** — bot ishlayotganini tekshirish.
4. **`avto_ishga_tushirish_yoqish.bat`** — kompyuter yoqilganda avtomatik ishlaydigan qilish.
